## 📊 爬虫会做什么？

### ✅ 能爬取的数据（真实数据）

1. **App Store 信息**（最可靠）
   - App 版本号
   - 更新日期
   - 用户评分
   - 更新日志
   - 用户评论

2. **TechCrunch 新闻**（英文）
   - AccuWeather、Weather Channel 等国际新闻

3. **SEC EDGAR 数据**（美国上市公司，免费）
   - IBM (The Weather Channel 母公司) 财报

### ⚠️ 爬取困难的数据（需要额外工作）

1. **36氪、知乎**（中文新闻）
   - 有反爬机制
   - 需要登录或验证码
   - **建议**：手动收集或使用 Webz.io API

2. **中国企业工商信息**
   - 国家企业信用信息公示系统有强反爬
   - **建议**：
     - 方案 1：手动复制粘贴
     - 方案 2：购买天眼查 API（5000-20000元/年）

## 🔧 如何将爬虫集成到自动更新？

### 当前情况

现在的自动更新（`update-daily.js`）生成的是**模拟数据**。

### 集成步骤

1. **修改 `.github/workflows/daily-update.yml`**

在文件中添加 Python 环境：

```yaml
- name: 安装 Python 依赖
  run: |
    cd crawlers
    pip3 install -r requirements.txt

- name: 运行爬虫
  run: |
    cd crawlers
    python3 run_crawler.py
```

2. **替代 update-daily.js**

爬虫会直接更新 `data.js`，就不需要 `update-daily.js` 了。

3. **配置 API Key（如果使用）**

在 GitHub Secrets 中添加：
- `WEBZIO_API_KEY`
- `TIANYANCHA_API_KEY`

## 🆘 遇到问题？

### 问题 1：依赖安装失败

```bash
# 升级 pip
pip3 install --upgrade pip

# 重新安装
pip3 install -r requirements.txt
```

### 问题 2：爬虫运行报错

查看错误信息，常见原因：
- 网络问题（连不上目标网站）
- 网站结构变化（爬虫代码需要更新）
- 反爬机制（需要调整策略）

### 问题 3：数据没有更新

检查：
1. 爬虫是否成功运行？
2. `data.js` 文件是否更新？
3. 网页是否刷新缓存？（Command + Shift + R）
